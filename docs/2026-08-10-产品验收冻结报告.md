# PuddingTeams 产品验收冻结报告

> 日期：2026-08-10
> 结论：产品核心 MVP 验收通过；数据模型与核心 API 自此冻结
> 不包含：npm CLI/Web 分发、干净环境发行验收、Electron、Extension Host

## 1. 冻结结论

PuddingTeams 已用本机真实 Codex 与 Claude Code 跑通核心产品路径，并在同一份隔离数据上多次重启 server 验证恢复。当前可以冻结为：

- 产品核心模型完成；
- 核心路径没有已知阻断；
- 后续不再增加产品功能，恢复开发时直接进入发行线；
- 发行线只改变启动、静态资源装载、数据目录和桌面宿主，不重做房间、Session、Delegation、Goal 或 Artifact 语义。

## 4. 验收中修复的核心阻断

只修复了阻断既有核心路径的问题，没有增加新产品功能。

1. **跨 Workspace manager Session 发现错误**
   `PiSessionStore` 原先使用 `SessionManager.list(defaultCwd, sharedSessionDir)`，会按单一 cwd 过滤共享目录，也会受 macOS `/tmp` 与 `/private/tmp` 规范路径影响。现在按受管 `sessionDir` 使用 `listAll()` 发现 Session，打开时再由 Window owner 决定上下文。

2. **首启 solo Session 被误换号**
   pi 在第一条 assistant message 前惰性落盘。房间读取原先只查磁盘，会把仍在内存中的新 solo Session 当成丢失。现在存活判断统一包含 `sessions.isOpen(id)`。

3. **Decision/custom-message turn 使用陈旧 Goal 上下文**
   `sendCustomMessage(triggerTurn)` 不触发 pi 的 `before_agent_start`，导致普通 Session 转 Goal 后，自动续接仍可能看到上一轮上下文。Goal 状态现通过每次模型请求都会执行的 `context` hook 注入，普通用户消息与自动 custom-message turn 都读取最新 revision。

对应回归测试已加入 server 测试集。

## 5. 冻结的数据模型

以下实体及其关系是发行线的稳定产品契约。字段命名或关系如需破坏性调整，必须先更新本文、事实源文档与回归矩阵；不能在打包过程中顺手改模。

### 5.1 Workspace 与 Window

- `WorkspaceRecord`：`id/name/rootPath/canonicalPath/gitRoot?/managed/createdAt/lastOpenedAt`；
- `WindowConfig`：`id/type/members/workspaceId?/cwdSnapshot/sessions/activeSession/workerBindings/...`；
- direct identity：`(worker, workspaceId ?? cwdSnapshot)`；
- solo：固定单例；group：独立 Window；
- `cwdSnapshot` 是运行与恢复的不可变事实，Workspace 不是通用权限沙箱。

### 5.2 Agent 与资源

- `AgentConfig.connector` 只表达 Connector 绑定和运行配置；
- `AgentConfig.responsibility` 表达 `domain/owns/excludes/escalateWhen`；
- `AgentConfig.piResources` 表达 system prompt、Skills、Prompt templates 与 Workspace context 加载策略；
- `extensionRevision` 参与 worker Session 续接身份；
- 权限由 Connector/Agent/OS 执行，不能由 Workspace 文案替代。

### 5.3 Session、Goal 与决策

- Window 拥有一个或多个 manager Session，并明确 `activeSession`；
- `SessionWorkState` 的稳定字段包括：`sessionId/goal/responsibleAgentId/participantAgentIds/currentBrief/waitingOn?/nextAction?/completionBoundary/goalRevision/reviewMode/reviewerModel?/completionReviews/status/artifactIds/revision/timestamps`；`completionReviews` 只追加不覆盖，用于复核审计；
- `DecisionRequest` 必须属于 Goal Session，状态为 `pending/answered/cancelled`；
- worker `completed` 不等于 Goal `resolved`；Goal 完成仍受活动 Delegation、待决策和复核规则约束。

### 5.4 Delegation 与连续性

- `DelegationRecord` 冻结 `windowId/managerSessionId/workspaceId?/cwdSnapshot/agentId/agentRevision/operation`；
- Goal 委托同时保存 `intent/expectedOutcome/evidenceRequirements/completionBoundary`；
- 交接链使用 `parentDelegationId/handoffKind`；
- `workerBindings[managerSessionId][agentId]` 保存 `sessionHandle/targetWindowId/workspaceId?/cwdSnapshot/agentRevision`；房间 Session 归属、合法执行窗口与身份完全一致才允许 continue，新建房间 Session 不继承旧 handle。

### 5.5 附件与 Artifact

- 用户附件冻结到平台受控目录，通过消息把 `name/mediaType/size/path` 注入 manager；
- `ArtifactRecord` 保存 `path/snapshotPath/contentHash/origin/producer/delegationId/windowId/workspaceId?/cwdSnapshot`；
- Artifact 下载只读 `snapshotPath`，返回 ETag 与 `x-content-sha256`；
- Artifact 登记必须通过 `cwdSnapshot` realpath containment，不能登记项目外文件或越界 symlink。

## 6. 冻结的核心 API

发行线可以把 Web 和 server 改成同源，也可以改变监听端口，但以下路径与主要请求/响应语义保持不变。

### Workspace / Room / Session

- `GET|POST /api/workspaces`
- `GET /api/workspaces/browse`
- `POST /api/workspaces/pick-directory`
- `GET|POST /api/rooms`
- `GET|PATCH|DELETE /api/rooms/:id`
- `POST /api/rooms/:id/switch-workspace`
- `GET|POST /api/rooms/:id/sessions`
- `PATCH|DELETE /api/rooms/:id/sessions/:sid`
- `POST /api/rooms/:id/sessions/:sid/activate`
- `GET /api/sessions`
- `GET /api/sessions/:id/messages`
- `POST /api/sessions/:id/messages`，正文为 `content? + attachments?`
- `GET /api/sessions/:id/ws`
- `POST /api/sessions/:id/abort`

### Goal / Decision / Delegation 投影

- `GET|PUT /api/sessions/:id/work-state`
- `POST /api/sessions/:id/decision-requests`
- `POST /api/decision-requests/:id/answer`
- `GET /api/sessions/:id/work-state` 同时投影该 Session 的 decisions 与 delegations

### Agent / Extension / Artifact

- `GET|POST /api/agents` 与 `PUT|DELETE /api/agents/:name`
- `/api/agents/:name/connector`、`/pi-resources`、`/extensions`、`/probe`、`/secrets`、`/avatar`
- `/api/extensions/catalog` 与受开发者模式保护的安装/更新/卸载 API
- `GET /api/artifacts?windowId=&delegationId=`
- `GET /api/artifacts/:id/content`
- `/api/interactions/*` 保持 experimental；它不与 DecisionRequest 合并

冻结规则：新增可选字段或新端点可以向后兼容地评审；删除、重命名、改变身份键、改变状态机或把现有字段改成不同语义，均视为破坏性变更。
