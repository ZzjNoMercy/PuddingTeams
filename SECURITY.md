# Security Policy

## Supported versions

Security fixes are provided for the latest `1.x` release line. Development snapshots on `main` are not release channels.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's **Security → Report a vulnerability** flow for this repository and include:

- affected version and platform;
- reproduction steps or a minimal proof of concept;
- expected impact;
- any suggested mitigation.

We aim to acknowledge a complete report within 5 business days. We will coordinate disclosure after a fix or mitigation is available.

PuddingTeams executes local Agent CLIs and code-based Extensions with the permissions of the current user. Only install Extensions you trust, review requested permissions, and keep upstream CLIs and credentials updated.
