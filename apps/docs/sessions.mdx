Window 保存成员、项目目录和多段普通会话。每段 Session 有持久的负责人；Manager 与 Pi Worker 都使用 Pi SDK 原生消息历史。Workspace 是项目资源，Goal 是某段 Manager 会话的执行契约。

## 委派是单次工具调用

Manager 使用统一工具：

```json
{
  "workerId": "researcher",
  "task": "核对第三条新闻，必要材料见项目中的 sources.md",
  "parentDelegationId": "前一调用的 delegationId",
  "handoffKind": "followup"
}
```

每次调用都是 fresh Context，没有业务续聊参数。`parentDelegationId` 只表达当前 Manager 会话中的因果，不自动复制父结果、附件或上游私有历史；Manager 必须明确传入本轮所需材料。`delegationId` 标识单次执行，结果进入原 Manager 上下文。需要审批时通过同调用的 `respond` 恢复，不新建任务替代原调用。

执行过程、Receipt、产物和单次取消位于工具详情；执行 handle 不是可切换、输入、重命名或删除的普通会话。全局搜索将执行记录与原生会话分开，支持按调用 ID、Worker、来源会话、项目 ID 与 Goal ID 查执行记录。

## 原生 Worker 单聊

Pi Worker 使用自己的模型、指令、工具、MCP 白名单与知识授权，不获得 Manager 的 delegation 或 Goal 控制。一个 Worker/项目拥有一个 Window，里面可以新建多段独立会话。新建会话不会继承旧对话；切回原会话继续它自己的历史。负责人失效时历史保留只读。

非 Pi Connector 的单聊仍由 Driver 管理上游 handle，核对房间、项目、cwd 和配置修订后续接。Driver 的 continue/respond 是连接器协议能力，不表示 Manager 单次委派拥有续聊能力。未支持原生忙碌输入或快照导入的连接器不开放相应操作。

## 运行中输入

聊天输入框的模型菜单显示当前会话的提供方、完整模型 ID 和配置端点；同名模型可能通过不同提供方调用。设置页的“全局后备”仅用于未明确指定模型的新会话，已有会话和 Manager、Worker 的明确模型配置优先。

Pi 原生会话运行中可直接回车追加，消息以 `followUp` 排队，并立即在转录底部显示为“等待中”气泡。气泡上的“引导”把该消息转为 `steer`（在 SDK 可处理的工具/回合边界插队消费，不强制终止在飞命令）；“删除”把它移出队列。followUp 在自然收尾时消费。真正停止走输入框的停止按钮——运行中发送键即停止键。

返回 `disposition=queued`、`persistence=pending` 仅表示 SDK 受理，尚不等于消息写入历史或模型已消费。相同操作键重试不重复入队。无法唯一核对消费身份时保留未知状态，不自动重发。待消费输入阻止 Fork、切模型或重建；停止清理 SDK 队列并保留附件。重启不自动重放丢失的内存队列。等待人工审批时，追加不能代替卡片上的批准或修改 Worker 内部上下文，此时也不能引导插队。含图片附件的排队消息不支持引导或单条删除（SDK 队列重建只携带文本）。

## Fork 是不可变快照

“Fork 到 Worker”冻结当前已提交分支、历史工具消息和附件，建立新身份的独立聊天；来源只作追溯。目标按自己的模型、指令和权限运行，创建后不自动执行。来源后续发言或删除不改变快照；目标发言也不自动回流。

活动 Goal、批准权限、运行控制与来源 Manager 的配置不复制。已完成 Goal/审批展示卡可作为历史阅读。目标必须在当前有效 Worker 范围内并明确支持 snapshotImport；超出完整导入预算时拒绝，不静默摘要。源有活动执行、等待审批或未消费输入时阻止创建。

## 权威记录与重启

| 内容 | 权威来源 |
| --- | --- |
| 原生对话与模型工具结果 | Session JSONL |
| 会话负责人、provider、快照来源 | `state/windows.json` v3 的 sessionRefs |
| 单次委派、完整归一化结果与 Receipt | `state/delegations.json` |
| 非 Pi 执行过程 | `state/delegation-timelines/*.jsonl` |
| Goal、WorkPlan、Decision | `state/work-states.json` |
| 快照 | ConversationSnapshots 的 manifest 与独立资产 |

展示卡不能反向覆盖权威状态。重启后未知执行效果先对账，不伪造运行中或成功。旧 Worker 输入队列不读取、不补投；显式诊断接口只列文件元数据，清理须另行明确操作。

删除普通会话不等于删除上游 Agent 的私有历史或审计台账。Window 至少保留一个会话，solo 是不可删除单例。
